# 스물여덟 자의 비밀

- 바로 하기: https://519-tn2020-71-bit.github.io/hangeul/

한글날 계기 교육용 서사 RPG입니다. 집현전 막내 학사가 되어 훈민정음이 만들어지고 펴지는 과정을 따라갑니다.

- 네 장(글 모르는 백성 / 소리를 본뜬 글자 / 집현전의 논쟁 / 스물여덟 자를 펴다), 15~20분
- 붉은 낙관(原)이 찍힌 글은 『훈민정음』 언해본 서문과 해례본 정인지 서문이고, 아래 풀이는 현대어로 푼 것입니다.
- 주인공 ‘막내 학사’와 저잣거리 백성 이야기는 꾸민 것입니다.
- 4장에서는 서문을 한 줄씩 읽으며 중세 국어의 특징(이어적기, 동국정운식 한자음, 방점, 어두자음군, 조사, 뜻이 바뀐 말 등)을 원문에서 찾습니다.
- 모두 마치면 학번·이름·한마디를 적어 수료증을 제출합니다.
- 그림은 AI로 생성했고, 배경음과 효과음은 게임 안에서 직접 합성합니다.

만든이: 경포고등학교 한예지 (게임 코드는 AI 도구 Claude와 함께 만들었습니다)
